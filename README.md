# TANgle - IPTV Checker

[English version](README_EN.md)

Веб-интерфейс для умного управления IPTV-плейлистами.
TANgle автоматически собирает единый M3U-плейлист из нескольких источников, проверяет каналы на доступность и скорость отклика, удаляет дубли и формирует актуальную ТВ-программу (EPG) только для работающих каналов.

Этот проект был разработан с использованием MiMo Code — AI-помощника для программистов от Xiaomi.

## Возможности

- **Проверка IPTV-каналов** — параллельное тестирование доступности каналов из M3U и M3U8-плейлистов с измерением времени отклика.
- **Формирование единого плейлиста** — объединение нескольких плейлистов; настраиваемое имя файла и публичный адрес сервера для ссылок в шапке плейлиста.
- **Умный дедуп каналов** — один канал на имя; победитель выбирается по доступности, затем по скорости (можно переключить на «самый быстрый»), с вкладкой «Дубли»: копии, выбор победителя, автоотсев проигравших и отключение мёртвых копий.
- **Управление группами** — автоматическая канонизация групп (EN→RU), предложения по объединению похожих групп с подтверждением, переименование, слияние, отмена объединений, массовые операции и исключение групп из плейлиста.
- **Управление каналами** — включение/отключение каналов, поиск, фильтры (живые/мёртвые/дубли/отключённые/по группам и источникам), сортировки, порционный рендер с бесконечной прокруткой.
- **Источники плейлистов по URL и из файла** — загрузка `.m3u` из браузера (до 20 МБ, UTF-8/Windows-1251), мгновенный импорт и замена файла у существующего источника.
- **Логотипы каналов** — берутся из источников, недостающие дозаполняются иконками из EPG; выбор детерминированный (приоритет источника) и не зависит от победителя дедупликации.
- **ТВ-программа (EPG)** — скачивание и слияние XMLTV; пересборка только при изменениях или по расписанию, потоковая отдача `epg.xml` и готового `epg.xml.gz` (для клиентов с gzip — без затрат CPU).
- **Статистика подключений** — отслеживание IP-адресов, устройств, истории обращений с фильтрацией по периоду и удалением.
- **Адаптивный веб-интерфейс** — удобное управление с ПК, планшетов и смартфонов.
- **7 тем оформления** — Dark, Light, Monokai, Dracula, Nord, Solarized, GitHub.
- **Мультиязычность** — переключение EN/RU в реальном времени.
- **Автоматизация** — встроенный планировщик для регулярной проверки плейлистов и обновления EPG.
- **Простота развертывания** — готовый Docker-образ для запуска одной командой.

## Быстрый старт

```bash
git clone https://github.com/shadalik/TANgle-iptv-checker.git
cd TANgle-iptv-checker
docker compose up -d
```

Откройте в браузере: `http://localhost:9239`

Логин по умолчанию: `admin` / `admin`

## Структура проекта

```
tangle/
├── app.py              # FastAPI сервер
├── database.py         # SQLite операции
├── checker_core.py     # Проверка каналов
├── groups.py           # Умное объединение и редактирование групп
├── epg.py              # Обработка EPG
├── static/
│   ├── index.html      # Основной интерфейс
│   ├── login.html      # Страница входа
│   └── translations.js # Переводы EN/RU
├── Dockerfile
├── docker-compose.yml
└── nginx.conf
```

## API

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/` | Веб-интерфейс |
| GET | `/<имя>.m3u` | Скачать плейлист (имя настраивается в настройках) |
| GET | `/p/<имя>.m3u` | То же для reverse-proxy (используется nginx.conf) |
| GET | `/epg.xml` | Скачать ТВ-программу (для клиентов с gzip — готовый `.gz`) |
| GET | `/epg.xml.gz` | Скачать сжатую ТВ-программу |
| POST | `/api/login` | Авторизация |
| GET | `/api/stats` | Статистика каналов |
| GET | `/api/channels` | Список каналов (с метками дублей) |
| PUT | `/api/channels/{id}/toggle` | Вкл/выкл канал |
| PUT | `/api/channels/{id}/group` | Изменить группу (применяется ко всем дублям имени) |
| DELETE | `/api/channels/{id}/override` | Сбросить ручную правку группы |
| GET | `/api/channels/{id}/duplicates` | Дубли канала |
| PUT | `/api/channels/bulk-group` | Массово назначить группу |
| GET | `/api/sources` | Источники плейлистов |
| POST | `/api/sources` | Добавить источник по URL |
| POST | `/api/sources/upload` | Загрузить плейлист файлом (.m3u/.m3u8) |
| POST | `/api/sources/{id}/file` | Заменить файл источника |
| GET | `/api/groups` | Группы, объединения, счётчики |
| GET | `/api/groups/suggestions` | Предложения по объединению групп |
| POST | `/api/groups/merge` | Объединить группы |
| PUT | `/api/groups/rename` | Переименовать группу |
| POST | `/api/groups/unmerge` | Отменить объединение |
| PUT | `/api/groups/exclude` | Исключить/вернуть группу |
| PUT | `/api/groups/exclude-bulk` | Массово исключить/вернуть группы |
| POST | `/api/groups/reset`, `/api/groups/reset-bulk`, `/api/groups/reset-all` | Сброс ручных правок групп |
| GET | `/api/duplicates` | Дубли по именам каналов (постранично) |
| PUT | `/api/duplicates/choose`, `/keep-best`, `/enable-all` | Управление победителем |
| POST | `/api/duplicates/auto`, `/undo-auto` | Автоотсев проигравших и отмена |
| GET | `/api/epg-sources` | Источники EPG |
| POST | `/api/epg/rebuild` | Пересобрать EPG (в фоне) |
| GET | `/api/settings` | Настройки |
| POST | `/api/check` | Запустить проверку |
| GET | `/api/access/log` | Лог подключений |
| DELETE | `/api/access/log` | Удалить лог за период |

## Настройки

- Интервал проверки каналов, таймаут и число потоков
- Интервал обновления EPG и период расчёта доступности
- Правила формирования плейлиста (по скорости и доступности)
- Правило выбора канала среди дублей (доступность → скорость или самый быстрый)
- Автоматическое объединение похожих групп (синонимы при импорте)
- Имя файла плейлиста и публичный адрес сервера
- Источники плейлистов (URL или файл) и источники EPG
- Авторизация

## Требования

- Docker и Docker Compose
- 768 МБ RAM (лимит контейнера в `docker-compose.yml`), 1 CPU
- 1+ ГБ дискового пространства (кэш EPG может занимать больше при многих источниках)
